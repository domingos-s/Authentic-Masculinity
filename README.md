# Authentic Masculinity — Private Project Starter Kit

This kit lets each member of the men's group use the same study setup while keeping his ChatGPT conversations private.

## Included

- `PROJECT_INSTRUCTIONS.txt` — paste into the Project's Instructions field.
- `Introduction.pdf` — actual book pages for the Introduction; this is the primary source.
- `Introduction_Knowledge.txt` — structured companion file for retrieval, discussion, and analysis.

## Setup

1. Create a new ChatGPT Project.
2. Name it **Authentic Masculinity Study** (or anything you prefer).
3. Open Project settings and paste the full contents of `PROJECT_INSTRUCTIONS.txt` into Project Instructions.
4. Upload `Introduction.pdf` and `Introduction_Knowledge.txt` as Project Sources.
5. Start chats inside your own Project. Do not join a shared Project if you want your personal reflections to remain private from the group.

## Good first prompts

- “Walk me through the Introduction and identify Troutt’s core argument.”
- “Give me five questions worth discussing with the guys from the Introduction.”
- “What parts of the Introduction deserve the most scrutiny biblically?”
- “Help me apply the Introduction personally without generic advice.”
- “What competing definitions of masculinity does Troutt introduce here?”
- “What does the Introduction suggest about shame and masculine formation?”

## Adding future chapters

For each chapter, add two files:

1. `Chapter_XX.pdf` — the actual book pages.
2. `Chapter_XX_Knowledge.txt` — the structured companion file.

The PDF is always the primary source. The knowledge file is an aid for retrieval, synthesis, and discussion.

## Use

These materials are for members who already have lawful access to the book. Do not redistribute the book pages beyond the group or use these files as a substitute for obtaining the book.
